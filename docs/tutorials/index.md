# Tutorials

Tutorials are **learning-oriented**. They walk you through a task step by step
so you can build confidence with yfin. Each tutorial assumes you can run
Python and have a working terminal.

| Tutorial                                  | What you'll do                                      |
|-------------------------------------------|------------------------------------------------------|
| [Getting started](getting-started.md)     | Install yfin and fetch your first quote table.       |
| [Convert to Polars](convert-to-polars.md)  | Switch the output from `pyarrow.Table` to Polars.    |

If you already know how to use yfin and just want to look something up, head
to the [Reference](../reference/index.md) or the [How-to guides](../how-to/index.md).
